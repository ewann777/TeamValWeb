# Fuentes de TeamVal

Outfit (Outfit Project Authors) para lectura, botones y navegación; Exo 2
(Exo 2 Project Authors, Natanael Gama) para títulos y estadísticas.
Ambas se distribuyen bajo SIL Open Font License 1.1, incluida junto a este archivo.

Origen de los TTF estáticos, sin modificar (Regular, Medium, SemiBold y Bold):
- https://github.com/Outfitio/Outfit-Fonts/tree/main/fonts/ttf
- https://github.com/googlefonts/Exo-2.0/tree/master/fonts/ttf

Se incluyen localmente para funcionar sin red y con minSdk 24; no requieren
fuentes variables ni Google Play Services. Los archivos cubren latín y español.
Los nombres de recurso Android están en minúsculas; no se modificaron los binarios.
